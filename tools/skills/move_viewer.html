🔊 = chiêu có âm thanh riêng; không có thì chiêu gây sát thương phát tiếng va chạm theo hệ lúc trúng đòn (hệ thường dùng tiếng hệ giác đấu). Mỗi chiêu chỉ có 1 bản chính thức, nằm trong assets/skills/<thế hệ>/<chiêu>/. Nhãn cho biết ảnh chính thức lấy từ đâu: Fallback, agy (bản vẽ cũ), tạm = hiệu ứng do code sinh, Code = tia vẽ bằng code. Chiêu chưa chọn dùng mặc định: tia Code → bản Fallback → bản agy cũ → code sinh; ảnh nào trống thì lấy ảnh đó từ nguồn kế tiếp.
Nguồn hiệu ứng:
Chính thức = ảnh đang nằm trong Skills (bản game dùng). Fallback = xem mọi ảnh Fallback để so sánh, kể cả ảnh trống hoặc bị loại. Code (thiết kế mới) = tia vẽ bằng code: quả cầu tụ năng lượng ở miệng → một tia liền mạch tới đối thủ → nổ tung khi trúng.
