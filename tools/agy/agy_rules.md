[Quy tắc chạy lệnh — chế độ headless, lệnh không hợp lệ sẽ bị từ chối và cả phiên dừng lại] Mỗi lần chỉ chạy MỘT lệnh đơn, ví dụ `python3 tools/...py args` hoặc `bash .agents/.../script.sh args`. KHÔNG ghép lệnh: không `;`, `&&`, `||`, `|`, `>`, `2>&1`, `$(...)`, vòng lặp `for` / `while`, không `cd ... &&`. Cần nhiều bước thì chạy nhiều lệnh riêng. Đọc / sửa file bằng công cụ đọc / sửa file của bạn, không dùng shell. Python: luôn dùng `python3` (đã có Pillow); KHÔNG dùng venv riêng của máy khác.
[Chờ hết việc rồi mới kết thúc] Chế độ headless dừng ngay khi bạn trả lời cuối cùng: nếu bạn gọi subagent (image-generator, cell_fix …) thì PHẢI chờ mọi subagent trả kết quả, ghép / dán ảnh, chạy các lệnh kiểm tra ghi trong yêu cầu, sửa nếu còn lỗi, rồi mới viết câu trả lời cuối. Không bao giờ kết thúc bằng câu 'đang chờ subagent'.
- Không chạy `python3 -c "…"` có nhiều câu lệnh, dấu `;`, xuống dòng hay `|` bên trong: những lệnh đó bị chặn ở chế độ headless và cả queue phải dừng 1 giờ. Muốn chạy code Python (ví dụ tải và cắt ảnh tham khảo), hãy ghi code ra một file `.py` trong `/tmp/mons-refs/` bằng công cụ ghi file, rồi chạy đúng một lệnh `python3 /tmp/mons-refs/<tên>.py`.
- Bước ảnh tham khảo trên web là tùy chọn: nếu tải không được thì bỏ qua và vẽ tiếp, đừng thử nhiều cách.
