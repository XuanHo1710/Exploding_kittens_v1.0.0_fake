## Cross-Check Findings

### 1. `[MAJOR]` `FX_MUZZLE` Player `actorId` (`1000 + idx`) Collides with Turret `>= 1000` Guard, Disabling Hero Tiers 2..4 Muzzle VFX, Styles & Casings
- **Locations:**
  - `server/src/game/bansung/world.ts:857` (`const actorId = 1000 + idx;`)
  - `server/src/game/bansung/weapons.ts:1638-1644, 1765-1772, 1856-1863, 2018-2025, 2073-2080` (pushes `FX_MUZZLE` with `hero.actorId`, `spec.idx`)
  - `server/src/game/bansung/gadgets.ts:91, 1755-1762` (`INITIAL_DEPLOYABLE_ID = 1000`, pushes `FX_MUZZLE` with `dep.id`, `projCfg.kindId`)
  - `client/src/bansung/render.ts:2783-2788` (`resolveFxActorWeaponTier`: `if (actorId >= 1000) return 1;`)
  - `client/src/bansung/vfx.ts:3037-3081` (`consumeFxEvent` for `FX_MUZZLE`)
  - `client/src/bansung/sound.ts:1744-1748`
- **Mismatch:** Both heroes (`1000 + idx`) and turret deployables (`>= 1000`) use `ownerActorId >= 1000`. Because `resolveFxActorWeaponTier` returns `1` for any `actorId >= 1000` and `consumeFxEvent` branches on `if (ownerActorId >= 1000)`, every hero gunshot/swing is misclassified as a turret shot:
  1. `weaponTier` passed to `spawnMuzzleFlash` (`vfx.ts:3077`) is doubly forced to `1`, so Tiers 2..4 `tierSpec.muzzleScale`, violet/cyan/white aura glow (`vfx.ts:749-767`), spark color/count (`vfx.ts:2371-2398`), and pixel star-flare accents (`vfx.ts:840-850`) never activate from server `FX_MUZZLE` events.
  2. `vfx.ts:3049-3055` interprets hero weapon `spec.idx` via `getProjectileConfigByKindId(weaponOrKindId)` instead of `getWeaponByIdx(weaponOrKindId)`, locks `scale = 0.85`, skips weapon-specific styles (`shotgun`, `laser`, `flame`, `emp`), bypasses the melee early-return (`vfx.ts:3058`), and never sets `emitCasing = true`, so `spawnWeaponCasing` (`vfx.ts:3078-3080`) is never called. (Side note: `sound.ts:1744-1748` suffers the same collision, mapping hero `FX_MUZZLE` to `'turret_shot'`/`'fx_thunder_arc'`.)

### 2. `[MAJOR]` Tiers 2..4 Evolved Bullet Tracers Are Unreachable in `drawProjectilePass`
- **Locations:**
  - `client/src/bansung/vfx.ts:482-513, 568-573` (`getEvolvedTracerStyle`, `resolveTracerStyle(kindId, flags = 0, weaponTier = 1)`)
  - `client/src/bansung/vfx.ts:581-640` (`drawTracerRibbon` accepting optional `weaponTier = 1`)
  - `client/src/bansung/vfx.ts:3385-3386` (`drawProjectilePass`)
  - `shared/src/bansung/types.ts:325` (`BANSUNG_BULLET_FIELDS = 6`), `server/src/game/bansung/world.ts:4004` (`[id, kindId, x, y, aimQ, flags]`)
- **Mismatch:** `resolveTracerStyle` and `drawTracerRibbon` implement full Mk.II–IV evolved tracer scaling/colors (`BANSUNG_WEAPON_TIERS[tier].tracerColor`, widened lengths, thicker core at `tier >= 3`, additive blending). However, `drawProjectilePass` (`vfx.ts:3385-3386`) calls `resolveTracerStyle(b.kind, flags)` and `drawTracerRibbon(..., tracerStyle, flags)` with no `weaponTier` argument, and the 6-field bullet network tuple (`BANSUNG_BULLET_FIELDS = 6`) carries neither `ownerIdx` nor `weaponTier`. All live projectile tracers render as Tier 1.

### 3. `[MAJOR]` `BANSUNG_STATUS_GACHA` Wire Payload Mismatch Breaks `spawnGachaUpgradeVfx` Tier/Color Selection
- **Locations:**
  - `server/src/game/bansung/world.ts:2923, 2963-2970` (`applyGachaPick`)
  - `client/src/bansung/render.ts:2960-2976` (`processBansungFxEvents` handling `BANSUNG_STATUS_GACHA`)
  - `client/src/bansung/vfx.ts:2495-2558` (`spawnGachaUpgradeVfx`)
- **Mismatch:** Server `applyGachaPick` pushes `evt.c = clampedIdx` (the 0-based chosen card index `0..2`), whereas `render.ts:2962-2969` interprets `evt.c` as a gun tier / color code (`>= 2 && <= 4` -> `BANSUNG_WEAPON_TIERS[tier].auraColor`, `1` -> `'#38bdf8'`, `0` -> `'#c084fc'`) and passes the resulting hex string into `spawnGachaUpgradeVfx(pos.x, pos.y, auraColor)`.
  - As a result, burst colors follow the clicked card slot rather than the picked card's rarity/tier/color (`0` -> violet, `1` -> cyan, `2` -> `BANSUNG_WEAPON_TIERS[2].auraColor` cyan `#38bdf8`), making the Mythic Gold (`#fbbf24`, `variant = 2`) and Emerald Heal (`#69db7c`, `variant = 3`) branches in `spawnGachaUpgradeVfx` unreachable via network FX.

### 4. `[MAJOR]` `FX_BLAST` `blastKind` Code Collisions Mis-Style Mines, Turret Thunder, Turret Expiry & Boss Attacks
- **Locations:**
  - `client/src/bansung/vfx.ts:3084-3149` (`consumeFxEvent` for `FX_BLAST`)
  - `server/src/game/bansung/weapons.ts:117-123` (`BANSUNG_BLAST_KINDS`: `frag: 0, stun: 1, rocket: 2, mine: 3, fireball: 4`)
  - `server/src/game/bansung/gadgets.ts:76-81, 1595, 1926` (`BANSUNG_BLAST_HE = 0, STUN = 1, CLUSTER_SUB = 2, TURRET_THUNDER = 3, TURRET_EXPIRE = 4, DRONE_PULSE = 5`)
  - `server/src/game/bansung/boss-colossus.ts:992, 1122, 1354, 2123`; `server/src/game/bansung/boss-sand.ts:938, 1502`
- **Mismatch:** Multiple server modules emit incompatible meanings on `FX_BLAST` `evt.a` (`blastKind`):
  - `blastKind === 3` maps to `'steam'` (`FxColor.Dust` smoke + `DecalKind.Scorch`) in `vfx.ts:3139-3140`. While Colossus Steam Vent (`boss-colossus.ts:2123`) expects steam, both `prox_mine` (`weapons.ts:121`) and `BANSUNG_BLAST_TURRET_THUNDER` (`gadgets.ts:79, 1927`) also emit `3`, turning mines into dust/scorch and hiding Thunder Turret electric/cyan FX.
  - `blastKind === 4` maps to `'fireball'` (`vfx.ts:3137-3138`), styling `BANSUNG_BLAST_TURRET_EXPIRE` (`gadgets.ts:1596`) as an arcane fireball blast.
  - `blastKind === 1` always triggers `'stun'` + `pushStunFx(..., 0, 300, true)` + 4 electric arcs + `triggerFlashbangOverlay` (`vfx.ts:3109-3134`), causing Colossus mortars (`boss-colossus.ts:993`) and Sand Beholder enrage roar (`boss-sand.ts:939`) to render cyan flashbang arcs and camera flashbang white-outs.

### 5. `[MAJOR]` 2.5D Z-Arc Bomb Tracker (`spawnBombFx` / `removeBombById`) Is Unwired at Runtime
- **Locations:**
  - `client/src/bansung/vfx.ts:1329-1598` (`evalBombKinematics`, `drawBombShadow`, `drawBombTelegraph`, `drawBombBody`)
  - `client/src/bansung/vfx.ts:2632-2699, 3242-3259, 3316-3351` (`spawnBombFx`, `removeBombById`, `step`, `drawGroundPass`, `drawBombPass`)
  - `client/src/bansung/render.ts:3569, 4217`
- **Mismatch:** `render.ts` calls `bansungVfx.drawGroundPass` and `bansungVfx.drawBombPass`, yet repository-wide search confirms `spawnBombFx` and `removeBombById` have **zero callers outside `vfx.ts`**. Because `this.bombs` is never populated from snapshots or `FX_BLAST` / projectile lifecycles, thrown grenades, stun canisters, cluster bombs, and mortars render only flat 2D sprites in `drawProjectilePass` (`vfx.ts:3374-3434`) — bypassing `Z_PROJ = 0.85` bounce arcs, height-scaled ground shadows, `d24` `drawBombTelegraph` danger circles/urgency blink, and `bomb_bounce` / urgency `mine_arm` SFX triggers.

### 6. `[MINOR]` Player Stun Cyan Tint Condition Is Mathematically Unreachable & Mob/Boss Entry Flash Is Bypassed
- **Locations:**
  - `client/src/bansung/vfx.ts:893-896, 945-976` (`STUN_FX_CONST.ENTRY_FLASH_MS = 90`, `BODY_TINT_ALPHA = 0.25`, `resolveStunPose`)
  - `client/src/bansung/render.ts:2011, 2290, 4107-4118`
- **Mismatch:** `resolveStunPose` computes `cyanAlpha = cyanPulse * 0.25` (bounded `[0, 0.25]`), whereas `render.ts:4118` checks `stunCyan > 0.25 ? 'cyan' : undefined`, which can never evaluate `true` (mobs and bosses use `> 0.16` at `render.ts:2052, 2326`). Additionally, `render.ts:2011, 2290` pass synthetic `nowMs - 180` as `stunEnteredAtMs`, which is permanently past `ENTRY_FLASH_MS` (`90ms`), suppressing `pose.whiteAlpha` entry flash on mob/boss stuns.

### 7. `[MINOR]` `drawScreenOverlayPass` Is Unused and Flashbang Decay Curve Diverges from `render.ts`
- **Locations:**
  - `client/src/bansung/vfx.ts:886-888, 1226-1248, 3477-3483` (`drawScreenFlashOverlay`, `drawScreenOverlayPass`, `getFlashOverlayState`)
  - `client/src/bansung/render.ts:166, 4326-4341` (`RENDER_CFG.MAX_FLASH_ALPHA = 0.65`)
- **Mismatch:** `drawScreenOverlayPass` has zero external callers. Instead, `render.ts:4326-4341` reads `bansungVfx.getFlashOverlayState()` and renders a linear decay (`peakAlpha * max(0, 1 - (ageMs - 35) / 650)` capped at `0.65`), diverging from `drawScreenFlashOverlay`'s exponential curve (`peakAlpha * (1 - t) * exp(-t * 1.45)`, capped at `0.62`).

### 8. `[MINOR]` Crowd LOD in `drawOverheadStunStars` Hides Half the Orbit, and Pet/SFX Hooks Have Minor Wiring Gaps
- **Locations:**
  - `client/src/bansung/vfx.ts:1025-1051` (`drawOverheadStunStars`), `vfx.ts:2899, 3439` (`syncPetState`, `drawPetPass`)
  - `client/src/bansung/render.ts:3098-3115, 3228-3275`; `server/src/game/bansung/world.ts:4031-4048`; `client/src/bansung/sound.ts:1838-1854`
- **Mismatch:**
  1. When `totalStunned > 16`, `drawOverheadStunStars` skips `!frontPass` (`vfx.ts:1026`) and drops `starCount` to `2` (`vfx.ts:1028`), yet still filters `if (isFront !== frontPass) continue;` (`vfx.ts:1050`), so only 1 of the 2 opposite stars draws at any time instead of 2 flattened stars. (Also `render.ts:3098-3115` calls both passes consecutively in the post-entity HUD pass rather than splitting around sprites.)
  2. `render.ts:3228-3275` feeds `bansungVfx.syncPetState` from `rawFrame.pets`, which `server/src/game/bansung/world.ts:4031-4048` never serializes on `BansungFrame` (`drawPetPass` in `vfx.ts:3439` also has 0 callers).
  3. `sound.ts:1838-1854` handles `FX_STATUS` events except `BANSUNG_STATUS_LEVELUP` (`7`) and `BANSUNG_STATUS_GACHA` (`8`), so level-up/gacha bursts play no `consumeFrameAudioEvents` SFX.

## Verified Invariants
- **`spawnLevelUpVfx` End-to-End Visual Wiring:** `server/src/game/bansung/world.ts:2871-2878` emits `[FX_STATUS, p.idx, BANSUNG_STATUS_LEVELUP, p.level, Math.round(p.x), Math.round(p.y)]`; `client/src/bansung/render.ts:2943-2959` calls `bansungVfx.spawnLevelUpVfx(pos.x, pos.y, lvl)` (`vfx.ts:2452-2490`), draws `'LEVEL UP!'` floating text, and triggers a `#fbbf24` local flash; dual gold/cyan `drawStunRing` shockwaves + `bansungFx` particles render cleanly in ground/additive passes.
- **`FX_BEAM` Protocol & Rendering Alignment:** `server/src/game/bansung/weapons.ts:2008-2015, 2278-2285, 2931-2938`, `boss-sand.ts:1680-1687`, and `boss-overlord.ts:1756` emit `[FX_BEAM, x1, y1, x2, y2, kind]` (`0 = rail`, `1 = shock/chain/sand beam`, `2 = overlord laser`), matching `vfx.ts:3151-3162` and `drawBeamTrail` (`vfx.ts:670-735`) as well as `sound.ts:1870-1871`.
- **Asset Manifest & Procedural Atlas Parity:** All 22 clip keys referenced in `vfx.ts` (`bullet_kinetic_sm`, `bullet_kinetic_md`, `bullet_shotgun_pellet`, `p_frag_grenade`, `p_stun_canister`, `p_rocket`, `p_prox_mine`, `rail_beam`, `plasma_bolt`, `thunderball`, `fireball`, `bullet_enemy_orb`, `cluster_bomb`, `muzzle_plasma`, `muzzle_flash`, `fx_muzzle_kinetic`, `fx_stun_star`, `ui_shadow_unit`, `fx_bomb_mortar`, `fx_explosion_he`, `fx_explosion_stun`, `fx_explosion_small`) plus all 10 `pet_cat_*` / `pet_tiger_*` keys are present in `database-ban-sung/manifest.json` (`sprites`). Procedural `ATLAS_GLOW` (`vfx.ts:193-200`), muzzle cone (`128 + f*32, 32, 32x32` at `vfx.ts:810-815`), and stun star (`224 + f*16, 32, 16x16` at `vfx.ts:1070`) sub-rects match `buildProceduralFxAtlas()` (`256x128`) in `client/src/bansung/particles.ts`, with canvas fallbacks available while images load.
- **Tier Specification Table Alignment (`BANSUNG_WEAPON_TIERS`):** `vfx.ts` (`getEvolvedTracerStyle`, `spawnMuzzleFlash`, `drawMuzzleFlashAdditive`) derives scales and tier colors (`#94a3b8`, `#38bdf8`, `#c084fc`, `#fbbf24`) directly from `shared/src/bansung/weapons.ts:2273-2369`, ensuring internal alignment once upstream `FX_MUZZLE` actorId and per-bullet tier delivery are fixed.
- **Pool Capacity, Tracer Clamp & Match Lifecycle:** Fixed pre-allocated pools (`MAX_FLASHES = 48`, `MAX_BEAMS = 32`, `MAX_SHOCKWAVES = 24`, `MAX_ARCS = 32`, `MAX_BOMBS = 64`, `MAX_EXPLOSIONS = 32`, `MAX_TRACKED_PROJECTILES = 512`, `MAX_PETS = 16`), velocity-clamped origin-safe tracer tails (`vfx.ts:603-605`), and lifecycle resets via `bansungVfx.reset()` (`client/src/components/BansungBoard.tsx:247, 271`) are intact. `npx tsc -p client/tsconfig.json --noEmit` exits cleanly (`0`).

## Verdict
**FAIL** — Five **MAJOR** cross-module integration/protocol defects prevent core `c21` behaviors from activating at runtime (Tiers 2..4 muzzle flashes and weapon-specific muzzle/casing VFX blocked by `actorId >= 1000` collision; Tiers 2..4 evolved bullet tracers bypassed; `BANSUNG_STATUS_GACHA` card index vs tier color mismatch breaking `spawnGachaUpgradeVfx`; `FX_BLAST` code collisions mis-styling mines/turrets/boss roars; and the 2.5D Z-arc bomb tracker `spawnBombFx`/`removeBombById` unwired).
