## Cross-Check Findings

### [MAJOR] 1. `client/src/bansung/sound.ts` — Muted BGM state causes unmute / autoplay unlock to drop BGM playback
- **Where:** `client/src/bansung/sound.ts#L1038-L1045` (`syncBansungMute`), `#L1070-L1074` (`unlock`), `#L1991-L2005` (`setBansungBgm`)
- **Detail:** `setBansungBgm(track, fadeSec, biome)` assigns `currentBgmKey = nextKey` and `currentBgmBiome = biome` (`#L1997-L1998`) *before* checking `isMuted()` (`#L2000-L2004`). When muted, it queues `pendingBgmTrack = { track, biome }` and returns early without creating/loading/playing any deck. When the user later unmutes (`BansungBoard.tsx#L282-L285` calling `syncBansungMute()`, or gesture `unlock()`), both `syncBansungMute()` (`#L1042`) and `unlock()` (`#L1072`) clear `pendingBgmTrack = null` *before* calling `setBansungBgm(...)`. `setBansungBgm` then hits `#L1993` (`if (currentBgmKey === nextKey && currentBgmBiome === biome && !pendingBgmTrack) return;`) and returns early without starting BGM until track or biome later changes.

### [MAJOR] 2. `scripts/bansung/fetch-audio-guns.mjs` + `meta-guns.json` — Untrimmed 14.1 s / 41.3 s casing MP3s and over-trimmed 49 ms rifle WAV
- **Where:** `scripts/bansung/fetch-audio-guns.mjs#L564-L571`, `#L854-L923`; `database-ban-sung/audio/sfx/weapons/meta-guns.json#L832`, `#L991`, `#L1042`, `#L1085`, `#L1128-L1137`, `#L1171`; `client/src/bansung/sound.ts#L1653`
- **Detail:** Because `ffmpegUsed` is `false`, `fetch-audio-guns.mjs#L856` writes compressed `.ogg`/`.mp3` downloads verbatim without trimming or resampling:
  - `sfx_wpn_casing.variations` (`fetch-audio-guns.mjs#L564-L571`, carried into `manifest.json`) includes `audio/sfx/weapons/sfx_wpn_casing_v2.mp3` (**`14,106 ms`**, `292,384` bytes, 2ch) and `audio/sfx/weapons/sfx_wpn_casing_v3.mp3` (**`41,300 ms`**, `931,793` bytes, 2ch), alongside `sfx_wpn_casing.mp3` (`1,933 ms`), `sfx_wpn_casing_shotgun.mp3` (`2,325 ms`), and `sfx_wpn_casing_spin.mp3` (`48,000 Hz`). `sfx_wpn_reload_shotgun.mp3` is also `4,232 ms`.
  - In `sound.ts#L1653`, voice duration uses `(hit.buffer.duration || spec.fallbackDur) / pitchRate`, so selecting casing variations downloads up to ~932 KB and holds WebAudio voice slots for 14–41 s (stealable at priority 0, but plays full Freesound preview loops rather than a single shell clink).
  - Conversely, `sfx_wpn_rifle.wav` was sliced by `firstTransientOnly` down to **`49 ms`** (`4,326` bytes at `44.1 kHz` mono), cutting off the rifle shot body/tail.

### [MAJOR] 3. `scripts/bansung/fetch-audio-fx.mjs` + `meta-fx.json` + `manifest.json` — `durationMs` on OGG/MP3 FX & BGM records synth fallback length instead of actual shipped file duration
- **Where:** `scripts/bansung/fetch-audio-fx.mjs#L966-L1020`; `database-ban-sung/audio/sfx/fx/meta-fx.json`; `database-ban-sung/manifest.json`
- **Detail:** Unlike `fetch-audio-guns.mjs#L876-L877` (which uses `inspectOggInfo` / `inspectMp3Info`), `fetch-audio-fx.mjs#L1020` unconditionally records `durationMs: wavResult.durationMs`. When `hasFfmpeg` is `false`, `wavResult` comes from the local synth WAV fallback (`#L966-L986`), so `meta-fx.json` and `manifest.json` report synthetic WAV lengths rather than actual `.ogg`/`.mp3` durations on disk:
  - BGMs: `bgm_boss` / `bgm_boss_chiptune` report `6,667 ms` vs actual Vorbis OGG **`71,724 ms`** (`3,025,318` bytes); `bgm_boss_epic` `6,667 ms` vs **`123,481 ms`**; `bgm_boss_rpg` `6,667 ms` vs **`114,338 ms`**; `bgm_desert` / `bgm_combat` `7,500 ms` vs **`98,400 ms`**; `bgm_lobby` / `bgm_menu` `8,571 ms` vs **`21,333 ms`**.
  - FX/Stingers: `stinger_wave` / `wave_start` report `375 ms` vs actual OGG **`5,000 ms`** (`205,473` bytes); `sfx_boss_overlord_spawn` / `stinger_boss` `655 ms` vs **`4,000 ms`**; `sfx_emp_charge` / `boss_alarm` `136 ms` vs **`1,979 ms`**; `mob_spawn` `159 ms` vs **`1,744 ms`**.
  - Additionally, `fetch-audio-fx.mjs#L971-L985` omits `maxDurationMs` in the synth fallback `normalizeWav` call (whereas `#L933` and `#L956` pass it).

### [MINOR] 4. `scripts/bansung/pack-manifest.mjs` + `database-ban-sung/LICENSES.md` — Synthesized `.wav` fallbacks attributed to OSS source packs
- **Where:** `scripts/bansung/pack-manifest.mjs#L812-L818`; `database-ban-sung/LICENSES.md`
- **Detail:** When `ffmpeg` is absent, `.wav` fallback files for compressed OSS entries (e.g., `audio/bgm/bgm_lobby.wav`, `audio/sfx/weapons/sfx_wpn_casing_v2.wav`) are locally synthesized (`GENERATED-SYNTH` / `generated_synth` in `meta-guns.json` and `meta-fx.json`). However, `pack-manifest.mjs#L814-L817` registers `entry.fallbackPath` under `{ ...m, sha256: m.wavSha256 || m.sha256 }`, causing `LICENSES.md` to attribute locally synthesized `.wav` files to `oss_oga_bgm_cc0` / `oss_freesound_casings` and upstream OSS URLs (and carry the compressed file's `durationMs` on the `.wav` row).

### [MINOR] 5. `database-ban-sung/sources.json` vs `meta-miragine.json` & `manifest.json` — Miragine audio mismatch & stale `audioFallbackWavRateHz`
- **Where:** `database-ban-sung/sources.json#L65`, `#L2078-L2084`; `database-ban-sung/sprites/miragine/meta-miragine.json#L1384-L1481`; `database-ban-sung/manifest.json`
- **Detail:**
  - `sfx_miragine_dead_1..6` (`sprites/miragine/SD_dead1..6.mp3`) are the only 6 compressed audio entries in `manifest.json` without a `.wav` `fallbackPath`. Meanwhile, `sources.json#L2078-L2084` declares 5 different `miragineReuse.audio` entries (`miragine_ui_btn`, `miragine_cha`, `miragine_cheer`, `miragine_dao`, `miragine_timer`) not present in `meta-miragine.json` or `manifest.json`.
  - `sources.json#L65` sets `"audioFallbackWavRateHz": 22050`, while `lib-pack.mjs`, `fetch-audio-guns.mjs#L51`, `fetch-audio-fx.mjs#L48`, and all emitted `.wav` files on disk use `44,100 Hz`.

### [MINOR] 6. `client/src/bansung/sound.ts` vs `manifest.json` & boss modules — Indirect `synthFallback` lookup gap & 8 `SFX_SYNTH_ALIAS` boss/mortar keys absent from `manifest.json`
- **Where:** `client/src/bansung/sound.ts#L1083-L1093`; `server/src/game/bansung/boss-colossus.ts#L158-L168`, `boss-overlord.ts#L861,L1719`, `world.ts#L2323-L2465`
- **Detail:**
  - `resolveCanonicalKey` (`sound.ts#L1085-L1086`) only accepts `manifestMap.get(id)?.synthFallback` if that value is a direct key in `CANONICAL_DEFS`, without chaining through `SFX_SYNTH_ALIAS[manifestAlias]`. Numerous `manifest.audio` entries specify `synthFallback` values that only exist in `SFX_SYNTH_ALIAS` (e.g., `expl_bomb_1` -> `explode_he`, `sfx_wpn_pistol` -> `gun_pistol`, `boss_beam` -> `boss_beam`). All `253` current manifest keys still resolve via `SFX_SYNTH_ALIAS[id]` at `#L1087-L1091` (`0` silent fallbacks to `ui_click`), though newly added manifest keys could silently hit `ui_click`.
  - `SFX_SYNTH_ALIAS` includes 8 keys (`sfx_laser_charge`, `boss_death`, `boss_bolt`, `boss_cleave`, `mortar_launch`, `mortar_explode`, `shield_up`, `shield_shatter`) referenced in `boss-colossus.ts` and `boss-overlord.ts` that have no entries in `manifest.json` (and `world.ts#L2323-L2465` does not wire `onSfx`/`res.sfx` from `stepDreadColossus` or `stepOverlordBoss`, emitting `FX_*` wire events instead).

### [MINOR] 7. `scripts/bansung/fetch-audio-fx.mjs` — Missing license allowlist check, incomplete `--check`, and stale cache behavior
- **Where:** `scripts/bansung/fetch-audio-fx.mjs#L895-L904`, `#L925-L937`, `#L1062-L1086`
- **Detail:** Unlike `fetch-audio-guns.mjs#L50,L746-L750`, `fetch-audio-fx.mjs` does not enforce an `ALLOWED_LICENSES` allowlist; cache hits (`#L896-L904`) skip `sha256`/URL freshness checks and re-normalize `.wav` primaries in place (`#L925-L937`); and `runCheck()` (`#L1062-L1086`) only verifies magic bytes, `44.1 kHz / 16-bit`, and `peakDb <= -0.95` (omitting license allowlist, `sha256`, RMS, and channel count assertions).
