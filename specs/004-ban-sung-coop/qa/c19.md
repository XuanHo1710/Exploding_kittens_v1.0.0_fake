## Cross-Check Findings

### [MAJOR] F1 — Remote-player & fallback aim targets anchor to ground `(x, y)` instead of shoulder or `solveAimRigFromAngle`
- **Where**: `client/src/bansung/render.ts#L4088-L4093`, `client/src/bansung/anim.ts#L510-L588`, `client/src/bansung/input.ts#L1540-L1626`, `client/src/bansung/store.ts#L1337,L2073`
- **Detail**:
  - `anim.ts` defines `solveAimRigFromAngle` (`L510-L529`) to project `farDist = 1_000_000` from `(entX, entY - hero.shoulderLiftY + bob)` when only a quantized wire angle `aimRad` exists.
  - However, `render.ts` (`L4092-L4093`) passes synthetic short-range, **foot-anchored** target coordinates for every remote player (`targetX = drawX + Math.cos(aimRad) * 180`, `targetY = drawY + Math.sin(aimRad) * 180`). Because `solveHeroAimRig` (`anim.ts#L557-L575`) unconditionally prefers `(targetX, targetY)` over `aimRad`, `solveAimRigFromAngle` is bypassed at runtime.
  - Because `shoulderY = entY - hero.shoulderLiftY + bob` sits `17–19px` above `drawY` (`mascot`/`pyro` `17`, `ranger` `18`, `knight` `19`), aiming horizontally (`aimRad = 0`) creates `dy = +17..19px` over `~175px` (~`5.5°–6.2°` downward barrel tilt), skews overhead/downward aim angles, and introduces artificial `180px` parallax correction (`Math.asin(perp / safeDist)`).
  - The same foot-origin projection (`localDrawY + Math.sin(aimRad) * 160`) is used on non-pointer / mobile fallback aim paths (`input.ts#L1587-L1588,L1623-L1624`, `store.ts#L1337,L2073`), and `input.ts#L1545-L1548,L1601` computes wire `aimRad` relative to foot `originY` (`this.store.localDrawY`) rather than shoulder elevation.

### [MAJOR] F2 — Stale starter `WEAPON_RIG` / `muzzleOffset` in `shared/src/bansung/heroes.ts` and ground-level server muzzle bypass of `solveMuzzleWorld`
- **Where**: `shared/src/bansung/heroes.ts#L316-L401,L423-L526,L732-L768`, `client/src/bansung/anim.ts#L199-L215`, `shared/src/bansung/weapons.ts`, `server/src/game/bansung/weapons.ts#L1401-L1410`
- **Detail**:
  - `MASCOT_WEAPON_RIG`, `RANGER_WEAPON_RIG`, `PYRO_WEAPON_RIG`, and `KNIGHT_WEAPON_RIG` in `shared/src/bansung/heroes.ts` (`L339-L401`) hardcode obsolete `32x16` sprite metadata that conflicts with `WEAPON_RIG_SPECS` (`anim.ts#L199-L215`), `shared/src/bansung/weapons.ts`, and `database-ban-sung/manifest.json`:
    - `mascot` (`rifle`): `heroes.ts` has `32x16, grip=(10,10), muzzle=(30,7), eject=(15,7), recoilKick=4` -> `rig.muzzleOffset={x:32,y:-20}` vs canonical `40x18, grip=(10,9), muzzle=(38,7), eject=(16,6), recoilKick=4.5` (`8px` short).
    - `ranger` (`smg`): `heroes.ts` has `32x16, holdType:'rifle', grip=(11,10), muzzle=(27,8)` -> `rig.muzzleOffset={x:28,y:-20}` vs canonical `34x18, holdType:'pistol', grip=(9,9), muzzle=(32,7)` (`7px` short).
    - `pyro` (`plasma_rifle`): `heroes.ts` has `grip=(10,10), muzzle=(29,8), recoilKick=4` -> `rig.muzzleOffset={x:31,y:-19}` vs canonical `grip=(8,10), muzzle=(30,6), recoilKick=3.5`.
    - `knight` (`shotgun`): `heroes.ts` has `32x16, holdType:'heavy', grip=(10,10), muzzle=(30,7), shoulderR=9, recoilKick=6` -> `rig.muzzleOffset={x:34,y:-22}` vs canonical `42x18, holdType:'rifle', grip=(10,9), muzzle=(40,7), shoulderR=8, recoilKick=8.5` (`9px` short).
  - `solveMuzzleWorld` (`shared/src/bansung/heroes.ts#L732-L768`, re-exported by `anim.ts#L42,L108`) has zero server callers: `server/src/game/bansung/weapons.ts#L1401-L1410` (`computeGroundMuzzle`) spawns bullets and `FX_MUZZLE` from foot height (`hero.y + Math.sin(hero.aimRad) * fwd`), `17–19px` below rendered shoulder/barrel height. Additionally, `shared/src/bansung/weapons.ts` `muzzleOffset` encodes absolute cell coordinates for `plasma_rifle` (`[30, 6]`), `railgun` (`[36, 7]`), and `lightning_staff` (`[34, 7]`) instead of grip-relative offsets used by kinetic/explosive weapons.

### [MINOR] F3 — Clock-domain mismatch (`visualTimeMs` vs `performance.now()`) in `resolveHeroAnim` & `render.ts`
- **Where**: `client/src/bansung/store.ts#L1564,L1677,L1793,L1891-L1914`, `client/src/bansung/motion.ts#L997,L1129,L1799,L2021-L2023`, `client/src/bansung/render.ts#L3291-L3302,L4108,L4137,L4153`, `client/src/bansung/anim.ts#L698-L704,L864-L870`
- **Detail**: `store.ts` timestamps `atkAt` and `hitFlashAt` with `performance.now()`, whereas `render.ts` supplies `visualTimeMs: bansungMotion.getVisualTimeMs()` (match-elapsed hitstop-scaled clock starting from `0`). In `anim.ts#L699-L704` (`visualTimeMs - input.atkAtMs`) and `L865-L867` (`visualTimeMs - input.hitFlashAtMs`), as well as `render.ts#L4108` (`resolveStunPose(..., p.hitFlashAt ..., visualNowMs)`), the subtraction becomes negative whenever page uptime exceeds match duration. Live rendering currently masks both via `tracker.lastAtkAtMs` edge checks (`anim.ts#L706`) and `render.ts#L4116-L4118` `nowMs` tint calculation, leaving stateless `resolveHeroAnim` callers broken.

### [MINOR] F4 — Tier-2 Miragine fallback keys ignore manifest's normalized `miragine_a*` sheets, plus dead `BANSUNG_HERO_DASH_CADENCE` & invalid `'cyber_ranger'` fallback

### [MINOR] F5 — Mk.II–Mk.IV barrel accents (`drawWeaponEvolutionAccents`) render gun-barrel geometry on `melee` and `staff` weapons

- **360° Hysteresis & Depth-Order Math**: `solveFacing` (`shared/src/bansung/heroes.ts#L654-L661`) and `solveAimRig` (`L664-L729`) implement exact shared hysteresis (`FACING_HYST_COS = 0.08`), behind-body z-order (`BEHIND_SIN_THRESH = -0.15`), recoil-only orbit clamping (`shoulderR - clampedRecoil`), and close-range parallax clamping (`MIN_PARALLAX_DIST = 22`, `DEADZONE_AIM_R = 12`).
- **Hero Anim Spec & Run Cadence Parity**: `BANSUNG_HERO_ANIM_SPECS` (`48x48`, `offX: -24, offY: -44`, `idle 4@6fps`, `run 6@14fps`, `shoot 3@24fps`, `dash 4@14.3fps`, `stunned 2@10fps`, `dead 4@10fps`) matches all `hero_*` entries in `database-ban-sung/manifest.json`; `client/src/bansung/motion.ts#L689-L698` consumes `BANSUNG_HERO_RUN_CADENCE` directly (`dy`, `sx`, `sy`, `stepSfx` on frames `0` and `3`), and `motion.ts#L503-L511` delegates dash deformation directly to `sampleDashVisualTransform`.
- **15/15 Client Weapon Pivot Parity**: Every weapon in `WEAPON_RIG_SPECS` (`client/src/bansung/anim.ts#L199-L215`) matches `shared/src/bansung/weapons.ts` `anim` (`frames`, `cellW`, `cellH`) and `recoilKickPx`, and matches `database-ban-sung/manifest.json` `cellW`, `cellH`, `offX = -gripX`, and `offY = -gripY` (`15/15` verified; `manifest.json` omits `muzzleX`/`muzzleY`).
- **Mk.I–Mk.IV Evolution Tier Visual Palette & Scale Parity**: `drawWeaponEvolutionAccents` (`anim.ts#L1046-L1169`) and `render.ts#L4161-L4171` match `BANSUNG_WEAPON_TIERS` (`shared/src/bansung/weapons.ts#L2273-L2360`) for Tier 2 (`#38bdf8`, `muzzleScale = 1.2`, cyan glow), Tier 3 (`#c084fc`, `muzzleScale = 1.4`, dual barrel + violet glow), and Tier 4 (`#fbbf24`, `muzzleScale = 1.65`, tri-barrel + halo + star crest + fire glow).
- **Build & Test Suites**: TypeScript checks (`client/tsconfig.json`, `server/tsconfig.json`) and asset/weapon suites (`bansung-assets.test.cjs` 8/8, `bansung-weapons.test.cjs` 31/31) pass cleanly.

## Verdict
**FAIL** — 2 `MAJOR` findings (`render.ts` foot-anchored `180px` remote targets overriding `solveAimRigFromAngle` and distorting 360° aim; stale `shared/src/bansung/heroes.ts` `*_WEAPON_RIG` / `rig.muzzleOffset` + server `computeGroundMuzzle` ignoring `solveMuzzleWorld`) and 3 `MINOR` findings (`visualTimeMs` vs `performance.now()` clock mismatch, unused `miragine_a*` manifest fallbacks + dead `BANSUNG_HERO_DASH_CADENCE` + `'cyber_ranger'` fallback, and gun-barrel evolution accents drawn on `melee`/`staff` weapons).
