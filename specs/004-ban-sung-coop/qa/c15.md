## Cross-Check Findings

### BLOCKER
None. Runtime sprite/audio paths resolve cleanly on disk, PNG/WAV/OGG/MP3 headers decode cleanly, and all `28` active `sourceId` values in `manifest.json` are permissive/internal/generated (`26` `CC0-1.0`, `1` `INTERNAL-MIRAGINE`, `1` `GENERATED-SYNTH`).

### MAJOR

1. **[MAJOR] `verify-assets.mjs` (and `bansung-assets.test.cjs`) silently skips all `sources.json` vs `LICENSES.md` pack cross-checks (`Object.entries(Array)` bug)**
   - **Locations:** `scripts/bansung/verify-assets.mjs:855-866`, `server/test/bansung-assets.test.cjs:356-363`, `database-ban-sung/sources.json`
   - **Detail:** `sources.json` stores `spritePacks` (27-element Array) and `audioPacks` (20-element Array) as arrays whose elements carry `id`, not as ID-keyed maps. Both `verify-assets.mjs` and `bansung-assets.test.cjs` iterate `for (const [id, info] of Object.entries(packGroup))`, binding `id` to numeric indices (`"0"`, `"1"`, ...). As a result, `licenseInfo.packs.has(id)` / `packIds.has(id)` is **always `false`**, so license parity between `sources.json` and `LICENSES.md` is never checked.
   - **Gap extension:** `verify-assets.mjs` also omits `sources.audioOptionalBundles` (10 entries, including 4 `CC-BY-4.0` entries for `oss_meta_oculus_pack1`) and `sources.miragineReuse.license` (`INTERNAL-MIRAGINE`) from `sources.json` license validation, and `generated_synth` is absent from `sources.json` (`spritePacks`/`audioPacks`) despite being used by `manifest.json`, `meta-mobs.json`, `meta-guns.json`, and `LICENSES.md`.

2. **[MAJOR] `LICENSES.md` records wrong `sourceId`, origin URL, and stale `sha256=` digests on all 11 synthesized `.wav` fallback files; `verify-assets.mjs` does not check `sha256=` digests**
   - **Locations:** `database-ban-sung/LICENSES.md` lines `225, 227, 229, 231, 233, 238, 240, 242, 251, 255, 268`; `database-ban-sung/audio/sfx/weapons/meta-guns.json`; `scripts/bansung/pack-manifest.mjs:813-818`; `scripts/bansung/verify-assets.mjs:725-731`
   - **Detail:** Eleven weapon/casing audio assets (`sfx_wpn_casing_shotgun.wav`, `sfx_wpn_casing_spin.wav`, `sfx_wpn_casing_v2.wav`, `sfx_wpn_casing_v3.wav`, `sfx_wpn_casing.wav`, `sfx_wpn_laser_retro.wav`, `sfx_wpn_laser_v2.wav`, `sfx_wpn_laser.wav`, `sfx_wpn_railgun.wav`, `sfx_wpn_reload_shotgun.wav`, `sfx_wpn_western_gun.wav`) have `.ogg`/`.mp3` primaries and synthetic fallback `.wav` files whose true metadata is stored in `meta-guns.json` under `wavFallback` (`origin: "synth_wav"`, `sourceId: "generated_synth"`, `license: "GENERATED-SYNTH"`, actual `.wav` SHA-256). Because `pack-manifest.mjs:813-818` spreads `...m` with `sha256: m.wavSha256 || m.sha256` instead of reading `m.wavFallback`, `LICENSES.md` stamps the primary `.ogg`/`.mp3` `sourceId` (e.g. `oss_freesound_casings`, `oss_kenney_scifi_gh`), primary URL/duration (e.g. `41300ms` Freesound MP3), and primary `.ogg`/`.mp3` `sha256=` digest onto all 11 `.wav` fallback rows (e.g. `sfx_wpn_casing_v3.wav` records `d875bb3d49f9` instead of disk `.wav` `b63daffbfccd`).
   - **Verifier gap:** `verify-assets.mjs:725-731` only checks that `prov.sourceId` exists in `licenseInfo.packs`, never verifying `sha256=` hashes in `LICENSES.md` against files on disk or `meta-*.json`.

   - **Detail:** `LICENSES.md` `## Source Packs` columns are `| sourceId | Pack Name | Author | License | Upstream URL | Version / Commit | Attribution Note |`. The 4-group regex captures column 3 (`Author`) into `upstreamUrl` (while column 4 `License` still parses accurately).

2. **[MINOR] `verify-assets.mjs` permissive `resolveBgmSynthKey` bypass and loose `gain` upper bound**
   - **Locations:** `scripts/bansung/verify-assets.mjs:256-264`, `scripts/bansung/verify-assets.mjs:644`, `scripts/bansung/pack-manifest.mjs:800`
   - **Detail:** `resolveBgmSynthKey` returns `true` for any `bgm_*` `synthFallback` string without verifying membership in `client/src/bansung/sound.ts` `CANONICAL_DEFS`. Separately, `verify-assets.mjs:644` accepts `entry.gain <= 2` while `pack-manifest.mjs:800` clamps `[0.05, 1.0]` (`manifest.audio` observed range: `0.28..0.95`).

3. **[MINOR] `manifest.audio[].durationMs` diverges from fallback `.wav` durations (and includes multi-second casing MP3s)**

   - **Detail:** Twenty `manifest.audio` keys pointing to the 11 synthesized `.wav` `fallbackPath` files (`120..279ms` actual WAV length) report only the primary `.ogg`/`.mp3` `durationMs` (notably `sfx_wpn_casing_v3`: `41300ms` MP3 vs `133ms` WAV fallback; `sfx_wpn_casing_v2`: `14106ms` vs `133ms`; `sfx_wpn_reload_shotgun`: `4232ms` vs `123ms`).

4. **[MINOR] `pk_xp_orb.png` dead runtime draw path, raw folder placement, `CC0-1.0` vs `GENERATED-SYNTH` metadata split, and `BANSUNG_PICKUPS` `anim` parity gap**
   - **Locations:** `database-ban-sung/sprites/tiles/pk_xp_orb.png`, `database-ban-sung/normalized/props/pk_xp_orb.png`, `database-ban-sung/sprites/mobs/meta-mobs.json`, `database-ban-sung/manifest.json` (`lines 5426, 5840, 7954`), `shared/src/bansung/enemies.ts` (`BANSUNG_PICKUPS`), `client/src/bansung/render.ts:1688-1691`, `client/src/bansung/sprites.ts`, `scripts/bansung/verify-assets.mjs:830-843`
   - **Detail:**
     - `pk_xp_orb.png` raw source is placed in `sprites/tiles/pk_xp_orb.png` while indexed in `sprites/mobs/meta-mobs.json` (`category: "pickup"`, `sourceId: "generated_synth"`, `license: "CC0-1.0"` — whereas `LICENSES.md` assigns `generated_synth` license `GENERATED-SYNTH`) and normalized to `normalized/props/pk_xp_orb.png` (`manifest.json` keys `pk_xp_orb`, `prop_pickup_xp`, `xp_orb`).

All `383` shared sprite refs and `57` shared audio refs from `server/dist/shared/src/index.js` plus all `TIER1_CLIP_KEYS` and `BGM_FALLBACK_PATHS` resolve cleanly; zero unreferenced normalized sprites, zero unreferenced audio files, and zero `_cache/` artifacts exist on disk (`verify-assets.mjs` exit `0`, `bansung-assets.test.cjs` `8/8` pass).
2. **`pk_xp_orb.png` binary & manifest integrity:** Both `database-ban-sung/sprites/tiles/pk_xp_orb.png` and `database-ban-sung/normalized/props/pk_xp_orb.png` are identical `333`-byte `64x16` `8`-bit `colorType: 6` (RGBA8) PNG strips (`4` frames @ `16x16`, `sha256: 5d05155a95e6072588027e35ae787467aa71616ddde71ba16709934848ac2740`), matching `manifest.json` entries `pk_xp_orb` (line 5426), `prop_pickup_xp` (line 5840), and `xp_orb` (line 7954) (`offX: -8, offY: -14, fps: 8, loop: true, sourceId: "generated_synth"`) and `LICENSES.md:417` (`sha256=5d05155a95e6`).
3. **`LICENSES.md` `## Source Packs` & active `manifest.json` licensing:** All `47` packs in `sources.json` (`27` `spritePacks`, `20` `audioPacks`) plus `internal_miragine` (`INTERNAL-MIRAGINE`) and `generated_synth` (`GENERATED-SYNTH`) appear in `LICENSES.md` `## Source Packs` (`49` rows) with exact license parity (`0` mismatches). Active `manifest.json` `sourceId`s (`28` distinct) resolve exclusively to `CC0-1.0` (`26`), `INTERNAL-MIRAGINE` (`1`), and `GENERATED-SYNTH` (`1`); none of the `4` optional `CC-BY-4.0` `oss_meta_oculus_pack1` entries in `sources.audioOptionalBundles` are referenced in `manifest.json` or `LICENSES.md` provenance rows.
4. **Metadata file SHA-256 parity:** Across all `6` `meta-*.json` files (`audio/sfx/fx/meta-fx.json`, `audio/sfx/weapons/meta-guns.json`, `sprites/fx/meta-fx.json`, `sprites/heroes/meta-heroes.json`, `sprites/miragine/meta-miragine.json`, `sprites/mobs/meta-mobs.json`), `0` SHA-256 mismatches exist against disk files, including all `11` `wavFallback` entries in `meta-guns.json`.

## Verdict: FAIL

Runtime asset loading and active permissive licensing pass, **but `c15` fails cross-check verification on two `MAJOR` provenance/verifier defects**:
1. `scripts/bansung/verify-assets.mjs:855-866` (and `server/test/bansung-assets.test.cjs:356-363`) iterates `Object.entries()` over `sources.json` pack arrays (`"0"`, `"1"`, ...), silently disabling `sources.json` vs `LICENSES.md` cross-checks, while omitting `audioOptionalBundles`, `miragineReuse.license`, and `generated_synth`.
2. `database-ban-sung/LICENSES.md` misattributes all `11` synthesized `.wav` fallback files in `audio/sfx/weapons/` to external CC0 packs and records the primary `.ogg`/`.mp3` `sha256=` hashes instead of `wavFallback` (`generated_synth` / `.wav` SHA-256 from `meta-guns.json`), undetected by `verify-assets.mjs`.
