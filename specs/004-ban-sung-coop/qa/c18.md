## Cross-Check Findings

1. **[severity: MINOR] Local movement prediction speed omits active speed multipliers and input coalesces straight runs at 10Hz**
   - **Locations**: `client/src/bansung/store.ts:1353-1392, 1509-1520` vs `server/src/game/bansung/world.ts:1574-1582`, `server/src/game/bansung/pickups.ts:919`, `server/src/game/bansung/weapons.ts:987-991`, `shared/src/bansung/enemies.ts:1876-1885`, `shared/src/bansung/weapons.ts:1547, 2809-2869`, `client/src/bansung/input.ts:1009-1035, 1699`
   - **Details**: `resolveLocalSpeed()` (`store.ts:1509-1520`) only computes `baseSpeed` or `baseSpeed * DOWNED_CRAWL_MULT` (`0.28`, matching `BANSUNG_CRAWL_MULT = 0.28` in `bot.ts:58`). Authoritative movement on the server (`world.ts:1575-1580`) scales speed by `(p.mods.moveSpeedMul ?? 1) * (p.gachaMoveSpeedMult ?? 1) * getHeroWeaponMoveMult(p.weaponState)`, including `swift_boots` (`+0.15` per stack, max 2), `skill_mobility` Gacha stacks (`+0.08..+0.32` per stack, capped at 6 in `world.ts:510`), and Railgun charge slowdown (`moveMult: 0.78`). Additionally, `input.ts:1699` invokes `store.recordLocalInput(seq, mx / 100, my / 100, predDtSec)` without passing `speed`, and `input.ts:1016-1035` coalesces steady straight-line holds to `BANSUNG_HEARTBEAT_MS` (100ms) while clamping `predDtSec <= 0.05s`.
   - **Impact**: Authoritative server state always wins via `reconcileLocal` (`store.ts:1419-1483`) and errors up to `RECONCILE_SNAP_ERR` (`96px`) are smoothed via `corrOffsetX/Y` (`Math.exp(-14 * dtSec)`), so gameplay remains functional without permanent desync; however, high stacked speed buffs or sustained straight-line runs produce continuous minor visual lag/rubber-banding relative to authoritative ticks.

2. **[severity: MINOR] `stepLocalPrediction` omits `BANSUNG_STATE_STUN` from `serverControlled`**
   - **Locations**: `client/src/bansung/store.ts:2027-2030` vs `client/src/bansung/store.ts:1375-1380, 1453-1457`
   - **Details**: Both `recordLocalInput` (`1375-1380`) and `reconcileLocal` (`1453-1457`) treat `BANSUNG_STATE_STUN` as server-controlled (skipping local prediction and re-simulation), whereas `stepLocalPrediction` (`2027-2030`) checks only `BANSUNG_STATE_DEAD`, `BANSUNG_STATE_DASH`, and `BANSUNG_PFLAG_DASHING`.
   - **Impact**: While stunned after `predictionUsed && localPredReady` is true, `stepLocalPrediction` continues rendering `localDrawX/Y = localPredX/Y + corrOffsetX/Y` (updating on newest-tick snaps and ignoring deltas `<= RECONCILE_IGNORE_ERR` (`2px`)) instead of using the interpolated `local.x/y` knockback trajectory as `DASH`/`DEAD` states do.

3. **[severity: MINOR] Non-default `subscribeHud(fn, 60)` path duplicates `refreshHudSnapshot()` and bypasses `immediateHud` fast-path**
   - **Locations**: `client/src/bansung/store.ts:949-1058` vs `client/src/components/bansung/HotbarShop.tsx:2256`
   - **Details**: `HotbarShop.tsx:2256` subscribes via `useBansungHud(60)` (`60 !== HUD_THROTTLE_MS` = `67`). `subscribeHud` (`961-995`) registers custom-throttle callers on `this.listeners` (invoked on every 30Hz `push()`) with an independent timer that calls `this.refreshHudSnapshot()` (incrementing `this.hudVersion` at `1075`) alongside the 15Hz `hudListeners` path (`1055-1058`). Because custom listeners sit outside `this.hudListeners`, `scheduleHudNotify(true)` (`immediateHud` on `gachaJustOpened`, `wavePhase`, `survival?.stageIdx`, or `syncSpectateNotify`) does not immediately wake `HotbarShop`.
   - **Impact**: Causes an extra `buildHudSnapshot()` allocation per ~67ms cycle when default and custom HUD listeners are both mounted, and can delay `HotbarShop`/`GachaDraftModal` re-render by up to `60ms` on immediate state transitions.

4. **[severity: MINOR] Prediction obstacle collision excludes destructible solid props**
   - **Locations**: `client/src/bansung/store.ts:1485-1502` (`integrateMove` / `resolveStaticCircle`) vs `server/src/game/bansung/world.ts:1583-1591`
   - **Details**: Client prediction resolves circles against `this.obstacles` (static map blocks from `BansungRoomView.obstacles`) and `this.playableBounds`, whereas server `moveCircleWithSlide(..., this.arena.obsGrid, ...)` also collides against solid destructible props (crates/barrels/cacti).
   - **Impact**: Minor transient penetration before server reconciliation pushes the predicted position back out.
